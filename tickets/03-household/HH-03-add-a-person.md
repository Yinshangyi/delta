## Story

As a **household member**, I want **to add someone to the household** so that **their income counts toward what we save**.

## Acceptance criteria

- [x] A person needs only a name
- [x] A person may have zero income sources
- [x] The household supports any number of people — never exactly two
- [x] The new person appears in Settings immediately
