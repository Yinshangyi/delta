## Story

As a **household member**, I want **one list of everything we are committed to paying** so that **I see the whole picture without hunting through sections**.

## Acceptance criteria

- [x] A single flat list mixing all commitment types
- [x] One icon per type — five types, five icons, not abbreviations derived from names
- [x] A type-appropriate summary line per row
- [x] Confirmed and estimated differ by more than colour
- [x] Totals stated honestly, distinguishing monthly commitments from scheduled tax
- [x] No separate nav sections for taxes, debt or budgets
