## Story

As a **household member**, I want **to see and edit one commitment in depth** so that **each type shows what actually matters about it**.

## Acceptance criteria

- [x] Debt shows initial against remaining, progress, percent repaid, payment, months remaining and payoff date
- [x] Tax shows its full dated schedule
- [x] The panel holds the commitment totals when nothing is selected, so the column never collapses
- [x] List rows show a hover state indicating they are selectable
- [x] Destructive actions sit apart from the primary action
