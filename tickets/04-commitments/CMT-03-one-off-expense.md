## Story

As a **household member**, I want **to record a one-time purchase on a date** so that **I can see what a large purchase does to the target date**.

## Acceptance criteria

- [x] Name, amount, single date
- [x] Affects only the configured month
- [x] A €15,000 purchase leaves every other month untouched
- [x] The target date recalculates on save
