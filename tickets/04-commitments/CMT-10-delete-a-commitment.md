## Story

As a **household member**, I want **to remove a commitment permanently** so that **the list reflects what is actually true**.

## Acceptance criteria

- [x] Confirmation names what is lost and the effect on the target date
- [x] Deleting a debt also removes its snapshots, and says so
- [x] Delete is not presented with the same visual weight as the primary action
- [x] Disabling is offered as the reversible alternative
