## Story

As a **household member**, I want **to write a scenario's changes into my real plan** so that **a decision I have made stops being hypothetical**.

## Acceptance criteria

- [x] Applying is explicit and confirmed, listing exactly what will change
- [x] Every override becomes a real edit to configuration
- [x] Nothing is applied until confirmed
- [x] After applying, the scenario no longer shows a delta against the baseline
- [x] The dashboard reflects the change immediately
