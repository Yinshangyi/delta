## Story

As a **household member**, I want **to stack hypothetical changes and see the effect** so that **I can weigh a decision before committing to it**.

## Acceptance criteria

- [ ] It is unmistakable throughout that nothing here is real yet
- [ ] Changes are added from the seven override types and individually removable
- [ ] Current and simulation shown side by side with assumptions, target date and months remaining
- [ ] The time delta is the outcome, decomposed where several changes are stacked
- [ ] Three exits: discard, preview, apply
- [ ] The hypothetical marking survives greyscale
- [ ] It can be opened in context from a commitment, income source or holding, pre-filling the first change
